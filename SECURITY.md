# Security Policy

## Supported Versions

SPM is currently pre-1.0. Security fixes are handled on the latest published version.

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability.

Report security concerns privately through GitHub's private vulnerability reporting if it is enabled for the repository. If it is not enabled, contact the maintainer listed on the repository or pub.dev package page.

Include:

- affected version or commit;
- steps to reproduce;
- expected impact;
- any suggested mitigation.
