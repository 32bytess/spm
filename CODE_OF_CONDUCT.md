# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Focus critique on ideas and code, not people.
- Accept feedback gracefully.
- Keep discussions relevant to the project.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Sustained disruption of project discussions.
- Any conduct that would reasonably make someone feel unsafe or unwelcome.

## Enforcement

Project maintainers may remove comments, close issues, or restrict participation when behavior violates this code of conduct.

Instances can be reported through the repository issue tracker or by contacting the maintainer listed on the package/repository profile.
